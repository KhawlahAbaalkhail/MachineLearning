Customer Segmentation using K-Means Clustering

This assignment focuses on implementing and evaluating a customer segmentation model using the K-Means Clustering algorithm on a credit card customer dataset. The project begins with importing the required Python libraries such as Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn. After loading the dataset, exploratory data analysis (EDA) is performed to understand the structure of the data, including checking dataset information, statistical summaries, and missing values.

Several visualization techniques are used to explore customer behavior and relationships between features. Data preprocessing is then applied by handling missing values and scaling the features using StandardScaler to prepare the data for clustering.

The K-Means clustering algorithm is implemented to group customers based on their financial behavior. To determine the optimal number of clusters, both the Elbow Method and Silhouette Score are used.

After training the model, customers are segmented into different groups such as high spenders, low activity customers, customers with high cash advances, and balanced users. Visualizations are used to better understand and interpret the resulting clusters.

Finally, the project demonstrates how customer segmentation can help businesses improve marketing strategies, personalize customer services, and better understand customer behavior.
